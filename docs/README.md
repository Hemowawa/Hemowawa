# HemoWawa - Landing Page Funcional (TB2)

Proyecto desarrollado para el curso **1ASI0784 - HCI for UX Design** (Universidad Peruana de Ciencias Aplicadas - UPC, Ciclo 2026-20).

## Descripción
**HemoWawa** es una solución digital centrada en el usuario para mejorar la adherencia a la suplementación con hierro y prevenir la anemia infantil en niños de **6 a 35 meses** en Lima Metropolitana, conectando a cuidadores principales, cuidadores secundarios y personal de salud del primer nivel.

## Estructura del Repositorio
- `assets/`: Recursos multimedia e íconos (`images/`, `icons/`, `fonts/`, `videos/`).
- `css/styles.css`: Hoja de estilos aplicando la paleta 60-30-10 (`#FFFFFF`, `#E0F2FE`, `#075985`, `#B91C1C`), tipografía Inter y criterios WCAG 2.1 AA.
- `js/main.js`: Lógica interactiva en JavaScript puro correspondiente a las 30 Historias de Usuario core.
- `pages/index.html`: Archivo HTML principal de la Landing Page.
- `docs/README.md`: Documentación del proyecto.
